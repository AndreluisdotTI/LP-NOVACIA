Como usar a tag

Para que o acompanhamento de conversões funcione, você precisa instalar a tag desse recurso, que é composta por uma tag do Google e um snippet de evento. Para instalar a tag com o Gerenciador de tags do Google, siga estas instruções.

Se alguma das suas páginas da Web foi desenvolvida com a tecnologia AMP, você precisará adicionar tags às versões AMP e HTML. Há instruções para ambas.

PÁGINAS HTML

Instale a tag do Google em cada página do seu site.
Abra o HTML de cada página.
Escolha entre estas opções:
Se você não instalou a tag do Google no seu site, copie a tag abaixo e cole-a entre as tags head (<head></head>):

<!-- Google tag (gtag.js) --> <script async src="https://www.googletagmanager.com/gtag/js?id=AW-18096407370"></script> <script> window.dataLayer = window.dataLayer || []; function gtag(){dataLayer.push(arguments);} gtag('js', new Date()); gtag('config', 'AW-18096407370'); </script>

Veja mais diretrizes em Como configurar a tag do Google.

Se você instalou a tag do Google no seu site usando outro produto do Google (por exemplo, o Google Analytics) ou outra conta do Google Ads, copie o comando "config" abaixo e adicione-o a todas as instâncias da tag do Google, logo acima da tag final </script>.

gtag('config', 'AW-18096407370');

* Se você ou uma conta de administrador já instalou a tag do Google no seu site durante a configuração da tag para outra ação de conversão, verifique se ela está presente em todas as páginas do site e se o comando config contém este ID de conversão da conta do Google Ads: AW-18096407370
Salve as alterações feitas nas suas páginas da Web.

Instale o snippet de evento na página de conversão, que é a página do seu site que os clientes acessam depois de concluir uma conversão. Um exemplo é a página que exibe a mensagem "Agradecemos sua compra".
Abra o HTML da página de conversão.
Copie o snippet abaixo e cole-o entre as tags head (<head></head>) da página, logo após a tag do Google.

<!-- Event snippet for Contato via WhatsApp conversion page --> <script> gtag('event', 'conversion', {'send_to': 'AW-18096407370/dY87CJWd3rccEMqGhbVD'}); </script>

Salve as alterações na sua página da Web.
PÁGINAS AMP

Siga estas instruções para todas as páginas criadas com a tecnologia AMP.

Instale a tag do Google em cada página do seu site.
Abra o HTML de cada página.
Escolha entre estas opções:
Se você não instalou a tag do Google no seu site, adicione estas duas tags:
Primeiro, copie a tag abaixo e cole-a entre as tags head (<head></head>), antes da biblioteca JavaScript do AMP.

<script async custom-element="amp-analytics" src="https://cdn.ampproject.org/v0/amp-analytics-0.1.js"></script>

Em seguida, copie a tag abaixo e cole-a entre as tags body (<body></body>) de todas as suas páginas AMP.

<!-- Google tag (gtag.js) --> <amp-analytics type="gtag" data-credentials="include"> <script type="application/json"> { "vars": { "gtag_id": "AW-18096407370", "config": { "AW-18096407370": { "groups": "default" } } }, "triggers": { } } </script> </amp-analytics>

Veja mais diretrizes em Como configurar a tag do Google.
Se você instalou a tag do Google no seu site usando outro produto do Google (por exemplo, o Google Analytics) ou outra conta do Google Ads, copie a linha abaixo e cole-a na seção "config" de todas as instâncias da tag do Google.

"AW-18096407370": { "groups": "default" }

Se você ou uma conta de administrador já tiver instalado a tag do Google no seu site durante a configuração da tag para outra ação de conversão, verifique se ela está presente em todas as páginas do site e se a seção "config" contém este ID de conversão da conta do Google Ads: AW-18096407370
Salve as alterações feitas nas suas páginas da Web.

Instale o snippet de evento na página de conversão, que é a página do seu site que os clientes acessam depois de concluir uma conversão. Um exemplo é a página que exibe a mensagem "Agradecemos sua compra".
Abra o HTML da página de conversão.
Copie o snippet abaixo e cole-o na seção "triggers" da tag do Google.

"C_LSEriJzM53A": { "on": "visible", "vars": { "event_name": "conversion", "send_to": ["AW-18096407370/dY87CJWd3rccEMqGhbVD"] } }

Salve as alterações na sua página da Web.
